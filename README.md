# PACTUM: la nueva polis

Simulador de gobierno en acuarela ambientado en el Tolima. Cada decisión enseña un concepto de filosofía política, ciencias sociales o finanzas públicas: formas de gobierno y su corrupción, ética aplicada, presupuesto, deuda, inflación y desigualdad.
